# Featured Projects

## European Logistics Intelligence

End-to-end logistics analytics and Data Quality project built with Python, SQL, SQLite and Power BI.

The project simulates a European parcel-delivery network and covers the full analytical workflow from synthetic operational data generation to validation, cleaning, SQL modeling, route-risk analysis and management reporting.

### Project Scope

- 150,000 shipments
- 45 logistics hubs
- 25 European countries
- 660 routes
- 8 synthetic carriers
- 365 days of operations

### Key Results

- 89.59% on-time delivery
- 10.33% delayed shipments
- 2.70% no-scan rate
- 619.9 km average route distance
- 20.97 h average transit time
- €10.71 average shipping cost

### Data Quality Framework

A controlled Data Quality pipeline was built to inject, detect, evaluate and repair operational defects.

- 2,820 controlled logical defects injected
- 2,826 physical issue events detected
- 525 duplicate records removed
- 150,525 dirty rows reconciled back to 150,000 clean shipments
- 100% Precision, Recall and F1 on the controlled synthetic validation set

The project also includes:

- Route Risk Score
- Carrier Performance Score
- Hub Risk Analysis
- SLA Analysis
- Network Load Analysis
- Peak Season Analysis
- Weekend vs Weekday Analysis
- Geospatial route visualization
- Power BI executive dashboard

## Job Market Intelligence Platform

End-to-end job-market analytics platform built with Python, SQL, SQLite and Power BI.

The pipeline collects job-market data from multiple public APIs, normalizes heterogeneous datasets, validates data quality, classifies analytics roles, extracts technical skills and produces market insights.

### Project Results

- 1,833 jobs collected
- 466 analytics-related vacancies identified
- 89 skill-evaluable analytics vacancies
- 83 detected technical skills
- 93.26% skill coverage
- Python mentioned in 61.8% of evaluated analytics roles
- SQL mentioned in 56.18%
- Python + SQL together in 43.82%
- Salary and remote-work analysis
- Multi-source Data Quality methodology

The project demonstrates:

- API ingestion

- Job classification
- Skill extraction
- SQL analytics
- Salary analysis
- Data Quality controls
- Power BI dashboarding
